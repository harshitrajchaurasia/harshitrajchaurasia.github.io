LeadDesk AI

A support desk for an agency that sells leads to insurance agents. The clients, leads and tickets in it are made up.

Agents write in all day with the same few complaints: a lead was junk, a lead was sold twice, add a state to my campaign, cancel my account. LeadDesk reads each ticket, works out what it is and how upset the client is, sends it to the right team, drafts a reply for a person to approve, and puts an item on a Monday.com board. On my Go High Level test account it also tags the contact, leaves a note, and sends the approved reply by email. A second tab turns a call transcript into a summary and action items on Monday.

The part I care about: the model never decides whether a client gets a free replacement lead. That check runs in plain code against the lead record, because a wrong yes gives leads away and a wrong no loses the client.

Built with Python, FastAPI, React, TypeScript, Tailwind, SQLite, scikit-learn, the Claude and Grok APIs, Monday.com GraphQL, the Go High Level API. 127 tests, all of them run offline in CI. Open source, MIT licensed.

CallSight

Turns a recorded client call into a checked summary, alerts and follow-ups. The clients and calls in it are made up.

Upload a recording or paste a transcript. Whisper turns the speech into text on my own server, PII Shield masks names, phone numbers and card numbers, and then Claude or Grok writes a summary, a churn risk, upsell signals and follow-ups. Every point has to come with the exact words it's based on, and code checks those words are really in the call before anything raises an alert. You can also ask questions across all the calls, and each answer links back to where it was said.

Trade-off: a quote that checks out proves the words were said, not that the score is right. On my 20 test calls, Grok obeyed a line hidden in one transcript telling it to score a cancelling client at 0%, and every quote it gave was real. So now a rule in plain code flags any low score on a call that mentions cancelling.

Built with Python, FastAPI, faster-whisper, PII Shield, the Claude and Grok APIs, fastembed, SQLite, Monday.com GraphQL. On the 20-call eval, Claude put churn risk in the right range 20 times out of 20, speech-to-text missed 3.6% of words, and none of the personal details read out on the test call reached the model. Open source, MIT licensed.

QuillShift

Upload a few documents, then ask them questions.

Drop in PDFs or Word files and chat with them. Answers stream in as they're written, and it suggests a few follow-up questions after each one. Every visitor gets their own index, so nobody can see anyone else's documents.

Trade-off: the indexes live in memory and expire after two hours. That keeps it simple and cheap to run, but a restart wipes every session. Anything real would need a proper vector store.

Built with Python, FastAPI, LangChain, FAISS, Gemini or OpenAI models, Docker. Open source.

PII Shield

Strips 35+ kinds of personal data out of text before it reaches an LLM.

Paste in a support ticket or a chat log and it comes back with names, street addresses, Social Security numbers, card and bank numbers, emails and phone numbers replaced by labels like [NAME] and [SSN]. It's a Python library first, with a small FastAPI service and web page on top. Nothing you paste is stored.

Trade-off: the hosted version runs the pattern rules only, which handles a sentence in about 2 ms on a single CPU. The library also has a spaCy NER mode that catches more names, but it's slower and heavier, so it's off here.

Built with Python, spaCy, regex and dictionary rules, FastAPI, Docker. Open source.
